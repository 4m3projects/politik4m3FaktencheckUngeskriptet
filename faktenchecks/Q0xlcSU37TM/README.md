Die Daten weisen den Todesfällen keine einzelne politische Ursache zu. Die vom Gast genannte Zahl bleibt offen: Die automatischen Umschriften weichen voneinander ab.

Eine frühere Disziplinarstrafe des Erstrichters ist belegt; die einschlägige Entscheidung dokumentiert eine mündliche Auskunft, keine Übergabe der Weisung oder einer Kopie.
